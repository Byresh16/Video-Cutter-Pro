## 🔧 Required Dependencies

Video Cutter Pro requires the following external tools:

### FFmpeg

FFmpeg is used for video processing, cutting, encoding, and format handling.

👉 **Download FFmpeg for Windows:**

[Download FFmpeg](https://ffmpeg.org/download.html)

After downloading FFmpeg, make sure `ffmpeg.exe` is available in the Video Cutter Pro application folder.

### 7-Zip

7-Zip is required only when using the **Create archive after trimming** feature.

👉 **Download 7-Zip for Windows:**

[Download 7-Zip](https://www.7-zip.org/download.html)

For Windows x64, download the **64-bit `.exe` installer**.
